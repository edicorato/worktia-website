# Worktia Landing

Landing page statica beta/pre-lancio per Worktia.

## Sviluppo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

La pagina non usa backend, tracking o integrazioni esterne. La CTA beta usa un link `mailto:beta@worktia.com`.
